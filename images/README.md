# Images

Drop your real image files here using these exact filenames. Until a file exists,
the site renders a clean labeled placeholder box in its place (handled in `script.js`).

| File | Used for | Suggested size / ratio |
| --- | --- | --- |
| `profile.jpg` | Header profile photo (shown circular) | square, e.g. 400×400 |
| `wltlo-menu.png` | Hero backdrop — dark room, spotlit chair | wide, e.g. 1600×900 (16:9) |
| `guns-on-ice.png` | Portfolio card thumbnail | 16:10, e.g. 800×500 |
| `carrot-farmer.png` | Portfolio card thumbnail | 16:10 |
| `refit.png` | Portfolio card thumbnail | 16:10 |
| `castle2d.png` | Portfolio card thumbnail | 16:10 |
| `castle2d-sketch.png` | Castle 2D art-process (sketch) | any |
| `castle2d-color.png` | Castle 2D art-process (colored) | any |
| `capsize-1.jpg` | CapSize photo gallery | any |
| `capsize-2.jpg` | CapSize photo gallery | any |
| `dissertation-1.png` | Dissertation card thumbnail | 16:10 |

Paths are **relative** (`images/...`) so the site works on GitHub Pages project
sites, Netlify, and when opened locally.
